What to know about the Microsoft Copilot app merger

By Elena Vance • 3 min read • Updated 2026-08-21

Key Takeaway

Microsoft is merging its Copilot and Microsoft 365 Copilot apps. Learn what this means for your data and which features are being removed on August 18.

Outline

  • How will the merger affect your current Copilot usage?
  • Which features are being removed from Copilot?
  • Why is Microsoft consolidating its AI applications?
  • What steps should you take to prepare for the transition?

Microsoft Copilot is a unified artificial intelligence interface that combines consumer-facing AI features with professional Microsoft 365 productivity tools. Microsoft is transitioning to a single, consolidated application to reduce user friction, effectively merging the previous standalone Copilot app and the Microsoft 365 Copilot platform into one centralized experience.

According to official documentation from Microsoft, this consolidation aims to simplify the ecosystem by removing the need for users to switch between separate applications depending on whether they are handling personal tasks or workplace productivity workflows. This move aligns with broader industry trends toward universal AI agents that function across multiple contexts, as noted by reports from The Verge.

How will the merger affect your current Copilot usage?

The impact of this merger depends on whether you currently use the standard consumer Copilot app or the enterprise-focused Microsoft 365 version. For most users, the transition will occur via an automatic app update, though some desktop users may need to download the new unified application to maintain access to their account data.

If you use Microsoft 365 Copilot, you should expect minor navigational adjustments within your existing interface after the update. If you are a standard consumer user, your previous chat history and saved content will migrate to the new platform, provided you sign in with the same credentials. Microsoft has stated that all content remains tied to the specific account used to generate it, ensuring that personal and professional data remains segmented despite the shared interface.

Which features are being removed from Copilot?

As part of this consolidation, Microsoft is discontinuing three specific legacy features: Podcasts, Deep Research, and Group Chat messages. These changes take effect on August 18, and users are advised to export or save any essential data from these specific tools before the cutoff date to avoid permanent loss.

1. **Group Chat:** After August 18, all messages and images within the Group Chat feature will become inaccessible. You must manually copy and save any information you wish to retain before this deadline. 2. **Podcasts:** The ability to generate new podcasts will be disabled. Furthermore, any previously generated podcasts will no longer be accessible through the platform; you must download these files locally if you want to keep them. 3. **Deep Research:** This feature will no longer be available to standard users. Following the deadline, Deep Research will be restricted exclusively to Microsoft 365 Premium subscribers, meaning non-subscribers will lose the ability to generate new deep-dive reports.

Why is Microsoft consolidating its AI applications?

The primary motivation behind this change is to reduce product fragmentation. Historically, Microsoft maintained distinct AI environments for consumers and enterprise clients, which created confusion regarding feature availability and subscription requirements. By merging these into a single application, Microsoft simplifies its development pipeline and provides a more consistent user experience across platforms.

Data indicates that maintaining multiple, overlapping software products often leads to technical debt and reduced feature parity. By centralizing the product, the company can deploy updates, security patches, and new features more efficiently, ensuring that all users benefit from the same underlying infrastructure regardless of their specific subscription tier.

What steps should you take to prepare for the transition?

To ensure your workflow remains uninterrupted, you should perform an audit of your current Copilot usage immediately. If you rely on any of the three features being sunset, prioritize extracting that data before the August 18 deadline.

1. Review your chat history to identify any important Group Chat threads you need to archive. 2. Download any generated Podcasts that you want to keep for future reference. 3. Identify if your workflow depends on Deep Research; if it does, verify your subscription status to determine if you will retain access after the transition. 4. Update your mobile and desktop applications as soon as the prompt appears to ensure you are utilizing the latest version of the unified platform.
