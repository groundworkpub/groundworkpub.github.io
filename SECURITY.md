# Security Policy

## Supported Versions
Only the latest release of this repository receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
To report a vulnerability or suspicious modification in this open research repository, email **security@gworky.com** or file an issue on GitHub.
